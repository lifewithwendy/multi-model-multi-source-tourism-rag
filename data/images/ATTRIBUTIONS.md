## Notes on Licensing

- **Wikimedia Commons** images are almost always CC BY-SA or CC0 — click "Use this file" on the
  file page to get the exact license text and author attribution string.
- **CC BY-SA** requires attribution AND that any derivative works be shared under the same license —
  fine for an academic project, just make sure this file credits the author.
- **CC0 / Public Domain** requires no attribution but it's good practice to still log the source.
- Avoid images with **"All Rights Reserved"** or no clear license — even for a university assignment,
  don't use these without explicit permission.
- If you generate any images (e.g. AI-generated placeholders for missing attractions), mark them
  clearly as `Generated (AI), no external source` instead of leaving blank fields.
